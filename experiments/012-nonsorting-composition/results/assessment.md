# Assessment

- Experiment 012 completed all 27 frozen conditions across the three non-sorting pairs selected solely by Experiment 011's endpoint gates. All referenced manifests, prompt lengths, model revision, outputs, traces, and checksums were verified.
- Per-step dual-prompt linear-logit mixing produced zero hybrids in nine midpoint runs, and final-state hard projection produced zero hybrids in nine midpoint runs.
- Direct DiffusionGemma prompting produced eight hybrids in nine runs under the frozen lexical gates: 3/3 for blocked BLAS matrix multiplication, 2/3 for CSR plus deque BFS, and 3/3 for batched NumPy image normalization.
- The remaining graph direct-prompt output clearly described deque operations and CSR `indices` plus contiguous slices, but corrupted `indptr` into a damaged `` ` `ptr` `` token. It is therefore a strict automated-gate failure even though the intended combination remains human-identifiable.
- For matrix multiplication, all three logit midpoints retained only BLAS-backed `np.matmul`; hard midpoints became generic NumPy-vectorization advice. Direct prompts combined cache-sized tiles with BLAS-backed block products in 3/3 runs.
- For graph BFS, one logit midpoint retained only deque queue operations and two became malformed. Hard midpoints retained generic queue advice but lost CSR. Direct prompts combined deque and CSR in 2/3 strict runs.
- For image normalization, all three logit midpoints were malformed memory-mapping or preallocation fragments, and hard midpoints drifted to unrelated generator-expression advice. Direct prompts combined bounded batches with NumPy float32 broadcasting in 3/3 runs.
- Midpoint source top-1 agreement remained high: 0.912 for matrix multiplication, 0.842 for graph BFS, and 0.801 for image normalization. Mixed top-1 choices matched neither source only 0.026, 0.062, and 0.064 of positions respectively, yet sequence-level parent concepts still did not compose.
- The sorting result therefore replicates across non-sorting workloads under the tested interfaces: Experiment 012 gives 0/18 numerical midpoint hybrids versus 8/9 direct-prompt hybrids.
- Across Experiments 008, 009, and 012, the endpoint-valid controlled comparison totals 0/42 numerical-mixing hybrids versus 17/18 direct-prompt hybrids. These aggregate counts remain exploratory and combine different pair structures within the same fixed model and representation family.
- Conclusion: endpoint decodability does not imply a smooth compositional midpoint. Linear final-state projection and linear per-step output-logit mixing repeatedly select one parent, become malformed, or drift to model priors, while explicit text instructions compose the same named techniques reliably.
- Scope: DiffusionGemma revision `f7f5b7f5fa82ffc52addd066915886d497f5517b`, repository revision `e897394`, three non-sorting workloads, seeds 42-44, eight denoising steps, 96-token canvases, and the exact Experiment 011 endpoint-valid prompts.
